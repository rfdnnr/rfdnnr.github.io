# rfdnnr.github.io

Personal site of Rafael Donner: a dial of words over a slow landscape video, with a glass card for each project.

- `src/content/cases/` holds one Markdown file per card. Edit the text there.
- `src/scripts/site.js` moves the dial and the cards. `src/styles/site.css` styles them.
- `npm run dev` runs it locally. Pushing to `main` publishes it with GitHub Pages.
- `python3 scripts/og/make.py` rebuilds the link-preview images after a headline changes.

Background videos from Pexels.
